# Session logs

Peter keeps categorized session logs at `~/Documents/Claude/session-logs/`. Categories are listed in `~/Documents/Claude/session-logs/categories.json`.

When a topic clearly relates to a logged category (home assistant, backpack work, DIY projects, etc.):
1. Check `categories.json` for matching categories.
2. List the matching category folder to find recent session logs.
3. Read the most relevant 1-3 logs and use prior decisions, open threads and outcomes naturally; don't dump raw logs.

Don't read session logs for unrelated or one-off questions. The session-logger hook saves them automatically on session end.
